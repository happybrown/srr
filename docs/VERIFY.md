# 스르륵 기기 검증 안내

검증용 앱(v0.1.0-poc)을 실제 기기에 설치해, 넷플릭스·유튜브 같은 앱이 화면 맨 앞에 있을 때도 스르륵이 뒤에서 제대로 동작하는지 확인하는 절차입니다.

## 1. 설치

가장 쉬운 방법은 [GitHub Releases](https://github.com/happybrown/srr/releases)에서 `.apk` 파일을 받아 설치하는 것입니다. 직접 빌드하려면:

```bash
./gradlew assembleGithubDebug
adb install -r app/build/outputs/apk/github/debug/app-github-debug.apk
```

- 직접 빌드한 개발용 APK와 Releases의 APK는 서명 키가 다릅니다. 그래서 하나가 설치된 상태에서 다른 하나를 그 위에 덮어 설치할 수 없습니다. 바꾸려면 먼저 지우고 설치하세요.
- APK 파일을 메신저 등으로 보내 설치하면 Android 13부터 '알림 접근'이 회색으로 막힙니다. 이때는 **앱 정보 → ⋮ → 제한된 설정 허용**을 먼저 누르세요. `adb install`로 설치하면 이 제한이 없습니다.
- 실시간 기록 보기: `adb logcat -s Sureureuk`

## 2. 권한 설정

앱을 처음 열면 권한 안내 화면이 나옵니다. 정확한 검증을 위해 **6개를 모두 허용**한 뒤 시작하세요.

| 권한 | 구분 | 확인하려는 것 |
|---|---|---|
| 알림 표시 | 필수 | 실행 중 알림, +5분/+15분 버튼 |
| 알림 접근 | 필수 | 미디어 세션으로 앱별 정지 |
| 알람 및 리마인더 | 필수 | 기기가 잠들어도 정확한 시간에 깨우기 |
| 배터리 최적화 제외 | 권장 | 밤새 서비스가 종료되지 않는지 |
| 다른 앱 위에 표시 | 권장 | 영상 위 오버레이 |
| 시스템 설정 변경 | 선택 | 화면을 빨리 끄기 |

## 3. 테스트 방법

홈 화면 오른쪽 위 **검증** 버튼을 누르면 검증 화면이 열립니다.

1. 테스트 버튼을 누릅니다. 10초 뒤에 실행됩니다.
2. 10초 안에 테스트할 앱(넷플릭스 등)으로 가서 재생합니다.
3. 결과를 확인합니다. 스르륵으로 돌아오면 **기록**에 ✓ 또는 ✗가 남아 있습니다.
4. 앱을 바꿔 가며 반복합니다. 다 끝나면 **공유** 버튼으로 기록을 내보낼 수 있습니다.

| 테스트 | 기록에서 볼 것 |
|---|---|
| 정지: 미디어 세션 / 미디어 키 / 오디오 포커스 | `✓ 정지됨` 또는 `✗ 여전히 재생 중`, 앱별 세션 상태 |
| 볼륨 줄이기 30초 | 단계별 dB 곡선, 귀로 들었을 때 자연스러운지, 끝나고 볼륨이 원래대로 돌아오는지 |
| 화면 끄기 | `✓ N초 만에 화면 꺼짐` 또는 `✗ 화면이 꺼지지 않음` (앞의 앱이 화면을 켜두는 중) |
| 영상 위 표시 15초 | 전체 화면 영상 위에 막대가 보이는지, +10분 버튼이 눌리는지 |
| 전체 흐름 | 볼륨 줄이기 → 정지 → 볼륨 복원 → 화면 끄기가 이어서 실행되는지 |

## 5. 이 테스트로 답하려는 질문

1. **빠른 설정 타일:** 알림창의 '슬립 타이머' 타일을 눌렀을 때 기록에 `✓ 타일에서 바로 실행`이 남나요, `투명 화면 경유`가 남나요? (Android 14 이상에서 확인)
2. **일시정지 후 화면:** 넷플릭스가 일시정지 상태에서도 화면을 켜두나요? 화면 끄기 테스트에서 `✗`가 나오면 그렇다는 뜻이고, 기본 화면 끄기 방식을 바꿔야 합니다.
3. **전체 화면 팝업 알림:** '다른 앱 위에 표시'를 끄고 전체 흐름 테스트를 했을 때, 전체 화면 영상 위에 팝업 알림이 뜨나요?
4. **삼성 절전:** 갤럭시에서 스르륵을 '절전 상태 앱'으로 지정한 뒤 30분 타이머를 켜고 화면을 끈 채 두면 정시에 동작하나요? 기록에서 `백업 알람으로 깨어남`과 `대기 지연 감지`가 있는지 보세요.
5. **볼륨 단계:** 볼륨 줄이기가 계단처럼 끊겨 들리는지, 블루투스 이어폰에서도 같은지 확인합니다.

## 6. 기기가 없는 환경에서 확인한 것

- `./gradlew assembleGithubDebug assemblePlayDebug`: 빌드 성공
- `./gradlew lintGithubDebug`: 오류 0건. 경고는 다음 세 종류뿐입니다.
  - 라이브러리 새 버전 있음
  - `commit()` 사용 (복원용 상태를 즉시 저장하려는 의도적인 선택)
  - mipmap 폴더 이름
- APK 확인: targetSdk 36, 포그라운드 서비스 타입 specialUse, 인터넷 권한 없음
- 실제 동작(정지, 화면 끄기, 타일, 오버레이)은 **기기가 연결되지 않아 아직 확인하지 못했습니다.**
